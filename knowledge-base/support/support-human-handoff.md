When you ask to be connected, the assistant opens a support request with Yene
Business Group and attaches the **full conversation** we have had, so you never
have to repeat yourself and the agent already has the context.

## What the request contains

- A reference for your request.
- The complete conversation transcript.
- Whether you were signed in, and if so, which business the request belongs to.

An agent only ever sees the account attached to the request - never another
business.
